# Expose a classified PowerDNS API

DANS will initially support PowerDNS Authoritative `>=5.1.3,<5.2`, vendor its OpenAPI 3.1 contract, apply a checked-in DANS overlay under `/api/v1/dans`, and generate one combined client used by its CLI, integration tests, and upstream adapter from the beginning. The overlay exhaustively classifies every operation: zone list/get/export and search are authenticated reads; zone `PATCH` is the only delegation-controlled write; every other PowerDNS operation is operator-only. Unknown operations and incompatible upstream versions fail closed. The compatibility surface is the pinned `/api/v1` contract, not PowerDNS metrics, web UI, or undocumented routes; DANS serves the combined contract at authenticated `/api/docs`.

DANS is a contract-faithful gateway rather than a byte-transparent reverse proxy. It validates and decodes a declared request once, authorizes that same typed value, re-encodes one upstream request, strips client authentication and hop-by-hop or forwarding headers, and injects the upstream key. Evidence-backed overlay corrections may repair discrepancies between the published contract and legal PowerDNS 5.1.3 requests. Upstream response status, body, and end-to-end headers remain unwrapped and unvalidated; DANS-originated errors retain PowerDNS's error shape.
