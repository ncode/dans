# Retire zone authority before deletion

DANS is the sole supported PowerDNS API and control-plane writer. It will retire a zone binding and revoke its delegations before forwarding one upstream zone deletion. An upstream success or absence completes deletion; failure or an ambiguous timeout leaves authority revoked for explicit operator reconciliation, rather than automatically restoring grants or retrying a mutation whose outcome may be unknown. Direct PowerDNS API access, `pdnsutil` zone lifecycle changes, and backend zone lifecycle edits are unsupported because DANS cannot distinguish an externally recreated zone generation safely. A recreated zone requires an explicit rebind and never inherits authority from its previous lifetime; PowerDNS replication and explicitly configured DNS protocols may still operate, but DANS audits only mutations passing through it.
