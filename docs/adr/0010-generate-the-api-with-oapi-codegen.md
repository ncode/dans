# Generate the API with oapi-codegen

DANS will pin `oapi-codegen` v2.8.0 as a Go tool and generate models, client, standard-library server, and strict-handler interfaces from the vendored PowerDNS 5.1.3 OpenAPI 3.1 contract plus the DANS overlay. DANS schemas use distinct Create, Patch, Read, and Page models, reject unknown request properties, and require response properties; evidence-backed overlays may correct upstream naming collisions or request-schema discrepancies. A direct smoke comparison showed that both `oapi-codegen` and Ogen compile the contract after small naming overlays, but `oapi-codegen` produces the smaller runtime surface and gives compatibility routes direct `net/http` control for faithful upstream responses; DANS will therefore use the official request-validation middleware before its explicit authentication and authorization layers while leaving proxied responses unmodified and unvalidated in production.
